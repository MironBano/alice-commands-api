# Реферальная программа — эпик (post-launch)

**Статус:** отложено до v1.0.1+ · **Дата:** 2026-07-08  
**Связано с:** [CONTENT-PRODUCT-ROADMAP.md](CONTENT-PRODUCT-ROADMAP.md) §8

## Решение v1.0

Рефералка **не входит** в первый релиз alice-commands-api. Мягкая монетизация на старте:

- `device_picks` в `GET /v1/smarthome/devices` (Market URL)
- Без ПДн, без invite-кодов в API

## Когда вернуться

Триггеры для эпика:

1. DAU стабилен 30+ дней после store release
2. Есть продуктовая гипотеза (пригласи друга → бонус в app)
3. Юридически согласована схема без хранения ПДн

## Черновик scope (не реализовано)

| Компонент | Идея |
| --------- | ---- |
| Deep link | `https://alicecommands.ru/invite/{code}` → Play Store + attribution |
| Backend | Таблица `referral_codes` (anonymous device hash), счётчик установок |
| App | Share sheet «Пригласить друга» |
| Награда | Косметика (тема) или ранний доступ к категориям — без денег на старте |

## Ограничения

- Не хранить email/телефон в referral API
- Маркировка рекламы (ERID) — **опционально v1.0**; см. `docs/SECURITY.md` §8

## Альтернатива

Партнёрские подборки (`device_picks`) + контентная ценность каталога — достаточно для v1.0.
